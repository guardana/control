# Trademarks

The marks claimed here are the product name "Guardana Control", the slug
`guardana-control`, and the binary names `guardana-control` and
`guardana-gateway`. There is no logo yet; if one is adopted, it is claimed on
the same terms. The marks are held by the project's maintainer, Konrad Karauda,
on behalf of the project.

The code is licensed under Apache-2.0. That licence covers copyright and
patents. It grants no rights to the marks, and section 6 of the licence says so
explicitly.

## What you may do

- Say that your product works with this one, or is built on it.
- Write about it, teach it, review it, and use its name to refer to it.
- Redistribute the software unmodified under the project's own name.

## What you may not do

- Use the name or a binary name for a modified fork, a repackaged distribution
  or a hosted service. Give it your own name, and say what it is derived from.
- Use the name so as to imply endorsement, certification, or an official
  relationship that does not exist.

The test to apply: naming the project in order to say what your software works
with is fine. Using the name so that someone could take your build for this
project is not.

## The name

"Guardana Control" is the project's name from its first release on. Changing it
now would break the module path and the proto package, and would need a record
of its own ([ADR-0025](docs/adr/0025-public-repository-merges-and-releases.md)).
