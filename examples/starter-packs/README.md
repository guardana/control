# Starter policy packs

Two policy documents to start from, each with the cases that prove what it
decides: `read-only` and `approval-for-writes`. Run `policy test` on a pack's
`cases` directory and `policy explain` on one case. What each rule does, what
the packs assume about the plane and what they leave unguarded is
[docs/reference/starter-packs.md](../../docs/reference/starter-packs.md).
